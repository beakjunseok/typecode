# TYPE//CODE

코드 문법 토큰(`const`, `=>`, `fmt.Println()`, `GROUP BY` …)을 하나씩 치는 개발자용 타자연습 게임.
오타는 에러 로그로 남고, 오타 없는 토큰이 이어지면 콤보 배율이 붙는다. 주간 랭킹은 서버에 저장된다.

## 게임 규칙
- 언어 7종: JavaScript · Python · Java · C · Go · Rust · SQL / 시간 30 · 60 · 120초
- 토큰을 끝까지 맞게 치면 자동으로 다음 토큰. 오타가 나면 맞는 키를 칠 때까지 진행되지 않음
- 글자당 10점 × 배율. 오타 없는 토큰 연속 10개 이상 ×1.5, 30개 이상 ×2.0
- 콤보 10마다 메탈릭 효과음 + 네온 파티클 (blur 4px → 2px). 효과음은 Web Audio로 직접 합성

## 구조
```
index.html        # 정적 클라이언트 (HTML/CSS/JS 단일 파일, 빌드 없음)
api/_lib.js       # 공통 로직: 주차 계산, 세션 서명, 제출 검증, Blob 저장/조회
api/session.js    # POST  게임 시작 시 서버 시각 기반 세션 토큰 발급
api/scores.js     # GET   이번 주 TOP 10 / POST 점수 제출
```

### 랭킹 설계
- **초기화 배치 없음**: 점수는 `lb/{KST ISO 주차}/` 경로에 쌓이고, 주가 바뀌면 새 경로를 읽는다. 자정 트래픽 스파이크나 리셋 원자성 문제가 생기지 않는다.
- **append-only**: 점수 1건 = Blob 1개. 기존 파일을 고치지 않으므로 동시 제출해도 기록이 덮어써지지 않는다. 데이터는 파일 경로에 인코딩해 `list` 한 번으로 보드를 만든다.
- **세션 서명**: 게임 시작 시 서버가 `{sid, language, duration, startedAt}`에 HMAC 서명한 토큰을 발급. 경과 시간은 서버 시각으로만 판단한다.
- **제출 검증**: 서명 불일치 401 · 값 형식/시간/속도/점수 상한 위반 422 · 같은 세션 재제출 409. WPM·정확도는 서버가 다시 계산한다.
- 서버를 못 쓰는 환경에서는 브라우저 로컬 랭킹으로 자동 대체된다.

### 알려진 한계
- 클라이언트가 보낸 키 입력 수를 상한 검증만 하므로, 상한 안쪽의 조작까지 막지는 못한다.
- IP 단위 rate limit이 없다. 필요하면 Vercel Firewall 규칙으로 `/api/*`에 건다.

## 배포
Vercel 프로젝트에 Blob 스토어를 연결하면 `BLOB_READ_WRITE_TOKEN`이 자동 주입된다. 별도 서명 키를 쓰려면 `TYPECODE_SESSION_SECRET`을 설정한다(없으면 Blob 토큰에서 파생).
